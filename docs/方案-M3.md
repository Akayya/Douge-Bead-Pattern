## 1. 去杂点

### 为什么放在 M3 第一件做
M2 的 1:1 采样会把原图的压缩噪点、抗锯齿边缘一并抄进来：一张 12 色的图里常出现零星的灰白格、描边旁的过渡色。
这类杂点占比不到 3%，但手工擦很烦，而且它同时也是「灰色色块」抱怨的余党。

### 算法（`data/PatternCleaner.kt`）

```
object PatternCleaner {
    enum class Strength(val sameLimit: Int, val passes: Int) {
        LIGHT(0, 1),   // 只动「8 邻域里没有一个同色」的孤立点
        MEDIUM(1, 1),  // 同色邻居 ≤1 就并过去（默认）
        STRONG(1, 3),  // 同 MEDIUM，但反复擦 3 遍
    }
    data class Result(val cells: IntArray, val changed: Int, val passes: Int)
    fun despeckle(cells: IntArray, width: Int, height: Int, strength: Strength): Result
}
```

单格判定（读旧数组、写新数组，同一 pass 内无顺序依赖）：

1. 跳过空格（`-1`）；
2. 统计 8 邻域（越界跳过、空格跳过）的色号频次；
3. 若无邻居 → 不动；
4. 邻居中与自身同色的数量 `same`，主色（频次最高）数量 `top`；
5. `same <= sameLimit` 且 `top >= 5`（8 邻域里过半）→ 改成主色，`changed++`。

安全性：1px 描边/细线的格子通常有 2 个同色邻居，`sameLimit = 1` 时不会被吃掉；只有真正孤立的点会被合并。
反复 pass 到 `changed == 0` 或到上限为止。

### 两个使用入口

- **图片转图纸页**：新增开关「自动去杂点」（默认开，MEDIUM），在 `ImageToPattern.build` 之后、进预览之前跑；预览数字后面标 `· 清掉 137 点`。关掉即可看原始效果。
- **详情页 / 编辑器菜单**：「去杂点」→ 弹强度三选一 → 执行并压入撤销栈 → Snackbar 提示 `清掉 N 个杂点`。

## 2. 编辑器

`ui/editor/EditorScreen.kt` + `ui/editor/EditorCanvas.kt`

### 数据结构
编辑直接在 `Pattern.cells` 的**可变副本**上做，退出时写回 `PatternStore`：

- `val cells = remember { pattern.cells.copyOf() }`（不进 Compose state，避免 3249 格全量重组）
- `val version = remember { mutableIntStateOf(0) }`，画布用 `version` 当重绘信号
- 撤销/重做：`ArrayDeque<IntArray>` 各一条，上限 30 步（57×57 ≈ 13 KB/步，30 步 ≈ 390 KB，可接受）
- 脏标记 `dirty`；返回时若有改动立刻 `PatternStore.save`，顶部显示「已保存 / 未保存」

### 画布交互

单指画、双指缩放平移。**不要用两个 `pointerInput` 分别挂 drag 和 transform**（会互相抢事件），
用一个 `awaitEachGesture` 循环：

1. `awaitFirstDown` → 记录按下格；
2. 循环 `awaitPointerEvent`：`event.changes.size == 1` → 画（上一格到当前格用 Bresenham 补点，快速划动不漏格）；`>= 2` → 双指变换（缩放 0.5×–8×、平移）；
3. 全部抬起后 = 一次绘制事务 → 提交一次撤销快照（不是每格一次，否则撤销栈三下就满）。

坐标换算：`cell = (screen - origin) / (cellSize * scale)`，超出边界忽略。

### 工具

| 工具 | 说明 |
| --- | --- |
| 画笔 | 画当前选中色 |
| 橡皮 | 置 `-1`（空格） |
| 油漆桶 | 4 邻接 flood fill，只替换同色连通块，遇空格停 |
| 吸管 | 取该格色号选为当前色 |

底部还有：撤销 / 重做、网格开关、色号开关、「更多」菜单（去杂点、清空、重命名）。

### 调色板

横向滚动色条，只显示**「我有」的色号**（与图片转图纸的 `onlyOwned` 口径一致，避免画出买不到的颜色）。
选中色加 2dp 描边，色号写在色块下方。长按某色 → 大号浮层显示色号 + 名称，方便对色。

### 色号显示

`PatternCanvas` 加参数 `showCodes: Boolean = false`：格宽 ≥ 14dp 时在格心画色号（字号随格宽自适应，
长色号如 `ZG12` 截断到 3 字符）。默认关闭，11×11 以上开了才有意义。

## 3. 施工模式

`ui/build/BuildScreen.kt`。入口：详情页「开始施工」。进度直接复用已有的 `Pattern.done: MutableSet<Int>`
（索引 = `y * width + x`），每次改动 debounce 500ms 落盘，退出/杀进程都不丢。

### 布局

```
┌ 顶部：进度 123 / 5865 颗 · 8% ─────────┐
│ 画布（复用 PatternCanvas + dim/highlight）│
│ 当前色 chip：A19 #FD7E77 150 颗  已勾 12 │
└ 底部：[逐色] [逐行]  色号列表/行号 ───────┘
```

### 两种视图

- **逐色**（默认）：色号按用量排序横向列表；选中某色 → 画布上该色不透明、其他色 20% 淡出；点格子打勾。
- **逐行**：从第 1 行开始，整行高亮（其他行淡出），底部「上一行 / 下一行」+ 行内未完成数；适合逐行铺豆。

### 交互与视觉

- 单击格子：切换 `done`；
- 已完成格子：画半透明灰罩 + 白色对勾（在缩放后仍能看清，勾用 `Path` 画）；
- 长按格子：清空当前色所有勾（危险操作，`AlertDialog` 二次确认）；
- 顶部进度条 + 百分比；`done` 只统计非空格子（`doneCount` 已有实现）。

## 7. 验收标准

- **去杂点**：拿 `assets/samples/ref-dog.jpg`（51×115、12 色）对比，孤立 1 格杂色消失 ≥ 90%，狗的黑描边不断线；
- **编辑器**：改 20 格 → 关掉 App 重开，内容还在；连画 25 笔后能撤销回到初始（30 步栈）；
- **施工模式**：勾 5 格 → 退出重进，勾选与百分比都在；百分比 = 已勾/总颗数且总颗数 = 非空格数。

## 8. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 单指画与双指缩放抢手势 | 不用两个 detector，自写 `awaitEachGesture` 按指针数分流 |
| 每次落笔重绘整块画布（3249 格） | 单 Canvas + `version` 触发，先实测；卡再上 dirty rect |
| 去杂点吃掉 1px 细节 | 强度可调 + 撤销兜底 + 导入页可关 |
| `done` 集合序列化 | 现有 JSON 存索引数组，最坏全勾也只有几 KB |
| 大图（115 行）在编辑器里格宽太小 | 双指放大到 8×，色号在 ≥14dp 时才画 |
