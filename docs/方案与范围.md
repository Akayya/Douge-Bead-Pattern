# 已定方案（v1 范围）

做给自己用的拼豆工具 App：**作品标准，不是产品标准**。不做账号、社区、云同步、会员、自动识别截图/PDF、二维码。

## 八个模块

1. **图纸库**：本地图纸列表、缩略图、尺寸/豆数/进度、改名删除复制。
2. **图片转图纸**：选图 → 裁剪 → 尺寸（含 29/57 预设）→ 色数限制 → 实时对比 → 存库。
3. **编辑器**：画笔、橡皮、油漆桶、取色、双指缩放平移、撤销 30 步、网格与色号开关、镜像。
4. **豆数统计**：总颗数、按色明细、成本单价可设、工时估算。
5. **施工模式**（核心体验）：逐行逐色高亮、点格打勾、进度百分比、退出保留。
6. **导出**：带网格与色号的 PNG；A4 分页 PDF（标页码、拼接位提示）。
7. **底图描图**：把截图半透明垫在画布下手工描（自动识别的替代方案——成本 1/10、准确率 100%）。
8. **色板管理**：内置 MARD 221 / 291，增删改；**每个色号带「我有 / 没有」开关**，转图纸时只在已有色号里做最近色映射。

## 关键决策

- **用底图描图代替自动识别**：他平台截图里白色格子与白底无法区分，画布边界不能自动判定；72×66 的图逐格核对人工成本不可接受。描图把准确率问题交给人的眼睛。
- **色号库存开关**：避免生成的图纸用一堆买不到的色号，直接决定可执行性。
- **屏幕 HEX ≠ 实物颜色**：内置色板是参考值，最终以实物色卡为准，编辑器里留长按校准的口子。
- **暂不引 Room / kotlinx.serialization**：纯文件 + `org.json` 足够，且绕开 AGP 9 内置 Kotlin 与外部 Kotlin 插件冲突。
- **PDF 用系统 `PdfDocument`**：不引第三方排版库。
