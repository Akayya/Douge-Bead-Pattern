## 下载安装

到 [GitHub Releases](https://github.com/Akayya/Douge-Bead-Pattern/releases) 下载最新的 `Douge-<版本>.apk`：

1. 允许浏览器或文件管理器「安装未知来源应用」
2. 点击 APK 覆盖安装，升级不会丢图纸和施工进度
3. 需要 **Android 11 及以上**，不挑品牌和机型

每个 Release 都附 SHA-256，下载后可自行比对。**卸载会清空 App 内全部数据**，换机或卸载前，请先在「关于 → 数据备份」导出一份 zip。

## 能做什么

### 🖼 图片转图纸

- 选图、裁剪，自动识别原图像素画的格子，裁剪框吸附格子线，一格不差
- 按你「有」的色号做最近色映射，可限定色数，自动去杂点
- 自动识别图案外的空白，不会给背景生成豆子
- 普通照片认不出网格时，退回按长边定格数，也能手动调整
- 支持自定义画布尺寸、旋转、翻转、裁边、加边

### 🎨 手绘与修改

- 画笔、橡皮、油漆桶、吸管、直线、矩形、左右镜像
- 30 步撤销，一次落笔算一步，画快了也不会漏格
- 整图「替换此色」、一键减到 N 色，总颗数不变
- 色号按色系挑选（黄 A、绿 B……），两百多色也不用凭颜色猜

### ✅ 施工模式

- 四种视图：全部、逐色、逐行、按板（29×29 或 58×58）
- 点格打勾，进度和剩余时间实时更新，退出再进进度还在
- 双指缩放、只看未完成、防误触，「下一处未完成」直接跳到目标格
- 按色一键勾完，长按清掉整行 / 整色 / 整板的勾
- 拼到 100% 时按用量扣减豆仓库存，每张图纸只扣一次

### 📦 算料与导出

- 自动统计豆数、成本、工时，色号明细带单价和库存
- 豆仓：记录每种色号还剩多少颗，算缺口和补货花费
- 导出 PNG（带色号清单，也可直接分享到微信 / QQ）
- 导出 A4 分页 PDF：页边界对齐 29 格拼豆板，打印后直接拼
- 导出材料单 CSV：Excel 双击打开，可直接当采购表

### 💾 数据安全

- 整库备份 / 恢复 zip，走系统文件选择器，不联网
- 本地自动快照最多保留 5 份，删图纸、恢复备份前自动留底
- 单张图纸可导出 `.json` 分享，对方导入即得完整图纸（含施工进度）
- 支持导入自定义色板 CSV，多套色板随时切换

### 🎯 色板

- 内置 MARD 221（基础卡）和 MARD 291（完整卡），可逐色标记「我有 / 没有」
- 屏幕颜色和实物对不上？长按色块校准 HEX，还能直接从照片取色

## 三分钟上手

1. **打开 App**：图纸库自带一张爱心示例图纸，可以先点开看看效果。
2. **建第一张图**：点右下角「图片转图纸」选一张像素画截图，或点「空白画布」从零画。
3. **开始拼**：进详情页点「开始施工」，按逐色或按板视图，拼一颗勾一颗。

## 常见问题

**要联网吗？要注册吗？**
不用。App 没有网络权限，不申请任何权限，也没有账号、广告和统计。

**换手机或卸载重装，图纸还在吗？**
图纸存在 App 私有目录，卸载会一起删除。请先在「关于 → 数据备份」导出 zip，新机再导入；平时也可以靠本地自动快照兜底。

**截图识别不出格子？**
普通照片没有网格，会自动退回「按长边定格数」。像素画请尽量用原图，别二次压缩；识别结果也能在界面上手动改。

**打印出来的 PDF 怎么拼？**
导出时选 29 格模式，每页正好一块标准板。页脚标了「← 与左页拼接 / ↑ 与上页拼接」，按标记裁齐叠放即可。

**颜色和实物豆子对不上？**
内置 HEX 是屏幕参考值，会受材质、批次影响。在色板页长按色块 → 校准，输入 HEX 或从照片取色，校准只存本机。

**支持哪些手机？**
Android 11（API 30）及以上即可。
