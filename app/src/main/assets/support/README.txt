把赞助二维码放这里（可选，不放也能正常运行）
========================================

需要的文件名（大小写敏感，PNG 或 JPG 都行，方形最佳）：

    alipay.png    支付宝收款码 / 赞赏码
    wechat.png    微信赞赏码 / 收款码

怎么拿到：
- 支付宝：App → 我的 → 收钱 → 「收钱码」截图，或用「赞赏码」
- 微信：App → 我 → 服务 → 收付款 → 「赞赏码」截图

放好之后重新打包一次 APK 就生效，App 里「关于 → 赞助支持」会直接显示。
图片只打进安装包，App 不联网、不上传、不需要相册权限。

注意：
1. 这是纯静态收款码，不接任何支付 SDK，也不做任何校验（无法确认谁付了多少）。
   所以千万别做成"付费解锁"，那既不符合设计也违反应用商店规则。
2. Google Play 对引导站外支付有额外限制；如果要上架 Play，这里应改成移除二维码，
   或换成 Play 内购的打赏项。国内商店 / 自己分发没有这个问题。
3. 赞助入口只出现在「关于」页，不弹窗、不锁功能、不催。
